**Зарплаты для донат-групп и персонала с AFK-защитой.**

Плагин раз в заданный интервал выдаёт игроку зарплату по его группе
(право `group.<name>`), выполняет привязанные к группе команды, отправляет
сообщения и показывает тайтл. Игроки, которые стоят на месте, зарплату не получают.

## Возможности

- 💰 Выплата зарплаты через **Vault** (любая экономика: EssentialsX, CMI и т.д.)
- ⏰ Два режима выплат: `GLOBAL` (payday для всех, как в SAMP) и `PERSONAL`
  (личный таймер от захода игрока), интервал настраивается в одном месте
- 🏆 **Приоритеты групп** — если у игрока несколько прав `group.*`, побеждает группа с наибольшим приоритетом
- ⌨️ **Команды от консоли** при выплате — список команд у каждой группы
- 🛡 **Тихая AFK-защита** — состояние отслеживается отдельно для каждого игрока
  и влияет только на выплату: без сообщений, звуков и тайтлов, поэтому плагин
  не конфликтует со сторонними AFK-плагинами
- 🔓 Право обхода AFK-защиты (`moonsalary.bypass.afk`)
- 💬 Сообщения, тайтлы и звуки полностью настраиваются, поддерживаются **HEX-цвета** (`#42fffc`)
- 🧩 **PlaceholderAPI** — любые `%placeholder%` в сообщениях (подключается опционально, без него плагин не падает)
- ⚙️ `/salary reload` — перезагрузка конфига, групп и таймеров без перезапуска сервера
- 📋 `/salary list` и `/salary info <игрок>` — просмотр групп и чужой зарплаты
- 🔌 Свои события для других плагинов: `SalaryPayEvent` (отменяемое) и `PlayerAfkEvent`
- 🧯 Честный старт: без Vault/экономики плагин дожидается конца запуска сервера,
  логирует одну понятную причину и отключается, вырегиструя `/salary` из command
  map - ни stacktrace, ни «зомби-команды» у неработающего плагина
- ⏸ Если Vault выключают на работающем сервере, выплаты ставятся на паузу
  и автоматически возобновляются при его возвращении
- 🧪 Покрыт юнит-тестами (JUnit 5 + Mockito)

## Установка

1. Установите [Vault](https://www.spigotmc.org/resources/vault.34315/) и любой плагин экономики.
2. Положите `MoonSalary-2.0.0.jar` в папку `plugins/`.
3. Запустите сервер — рядом с jar появится `plugins/MoonSalary/config.yml`.
4. Настройте группы и интервал, затем выполните `/salary reload`.

> **PlaceholderAPI** нужен только если в сообщениях используются плейсхолдеры `%...%`
> (например, `%servertime_HH:mm%`). Без него плагин работает в штатном режиме,
> а в консоль один раз выводится предупреждение.

Без Vault или плагина экономики MoonSalary не блокирует загрузку сервера
stacktrace'ом: он дожидается окончания старта (вдруг экономика зарегистрируется
позже), после чего выводит одну строку с причиной и отключается. Команда
`/salary` при этом вырегиструется из command map вместе с алиасами, поэтому
не остаётся «зомби» и не бросает `CommandException` - сервер отвечает
обычным «Unknown command». После установки зависимостей достаточно
перезапустить сервер или включить плагин вручную.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/salary` | Информация о своей зарплате | — |
| `/salary info <игрок>` | Информация о зарплате игрока | `moonsalary.admin.list` |
| `/salary list` | Список всех групп (по приоритету) | `moonsalary.admin.list` |
| `/salary reload` | Перезагрузка конфигурации, групп и таймеров | `moonsalary.admin.reload` |

Алиасы: `/msalary`, `/zp`. Для всех команд работает автодополнение.

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `moonsalary.admin.reload` | op | Перезагрузка плагина |
| `moonsalary.admin.list` | op | Список групп и информация о чужой зарплате |
| `moonsalary.bypass.afk` | false | Зарплата выдаётся даже в AFK |
| `group.<название>` | — | Право группы, выдаётся LuckPerms / PermissionsEx |

Названия прав настраиваются в `settings.permissions`, там же меняется префикс группы
(`settings.permissions.prefix`) — например, на `rank.`.

## Группы зарплат

Группа определяется по праву игрока: `prefix` + `name` из секции `groups`.
Для группы `vip` с префиксом `group.` это право `group.vip`.

```yaml
groups:
  vip:
    salary: 250          # сумма выплаты (можно дробную: 12.5)
    priority: 1          # чем больше - тем важнее группа
    commands:            # необязательно, команд может быть несколько
      - 'give {player} diamond 5'
    messages:            # необязательно
      - ''
      - '&f&6╔ &fThe salary hour has come!'
      - '&f&6╚ &fYou received &e{money} ⛂'
```

| Ключ | Тип | Обязателен | Описание |
|---|---|---|---|
| `salary` | число | ✅ | Сумма выплаты |
| `priority` | целое | — | Приоритет группы (по умолчанию `0`) |
| `commands` | список | — | Команды от консоли при выплате |
| `messages` | список | — | Сообщения игроку при выплате |

Команды выполняются от имени консоли, поддерживают `{player}`, `{money}`, `{group}`.
Группа без `salary` пропускается с предупреждением в консоли — плагин не падает
из-за ошибки в конфиге.

В комплекте идёт `config.yml` с примерами групп: `default`, `vip`, `premium`,
`legend`, `media`, `helper`, `moderator`, `admin`.

## Режимы выплат

| Режим | Поведение |
|---|---|
| `GLOBAL` | Payday: каждые `payout.interval` секунд зарплату одновременно получают все игроки с группой |
| `PERSONAL` | Личный таймер: первая выплата через `payout.interval` после захода на сервер, дальше с тем же интервалом |

- Интервал настраивается одним ключом `settings.payout.interval` (в секундах) для обоих режимов.
- В `PERSONAL` режиме нет опроса каждую секунду: планировщик просыпается ровно
  к ближайшему сроку выплаты (`runTaskLater` на дельту до дедлайна), обрабатывает
  всех должников и засыпает до следующего дедлайна. Между выплатами задачи
  не существуют вообще, а количество игроков не создаёт новых тасков.
- Окно выплаты потребляется всегда: AFK, отмена события `SalaryPayEvent` или лаги сервера
  не приводят к «догоняющим» двойным выплатам — экономика остаётся целой.
- После `/salary reload` режим и интервал применяются сразу; личные таймеры не сбрасываются
  и продолжают идти от сохранённого момента следующей выплаты.
- Игрок онлайн, но вне расписания (старт плагина, reload) получает точку отсчёта
  на следующей проверке; при выходе из расписания он убирается.

## Конфигурация

### `settings`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `enabled` | `true` | Полное включение/выключение плагина |
| `interval` | `3600` | Интервал выплаты, в секундах |
| `execute_commands` | `true` | Выполнять команды групп |
| `format_money` | `false` | Форматировать `{money}` через экономику (`$1,000.00`) |
| `title.enabled` | `true` | Показывать тайтл при выплате |
| `title.fade_in` / `stay` / `fade_out` | `20 / 70 / 20` | Тайминги тайтла, в тиках |
| `afk.enabled` | `true` | AFK-защита |
| `afk.check_interval` | `20` | Как часто проверяется позиция игрока, в секундах |
| `afk.threshold` | `300` | Сколько нужно стоять на месте, чтобы уйти в AFK, в секундах |
| `afk.ignore_rotation` | `true` | Не считать поворот головы движением |
| `permissions.enabled` | `true` | Включить систему прав |
| `permissions.prefix` | `group.` | Префикс права группы |
| `sounds.salary` | — | Звук выплаты: `enabled`, `sound`, `volume`, `pitch` |

### `messages`

| Ключ | Описание |
|---|---|
| `prefix` | Текст плейсхолдера `{prefix}`: вставляется только туда, где шаблон сам его запросил |
| `on_salary.enabled` | Отправлять сообщения группы при выплате |
| `on_salary.title` / `on_salary.subtitle` | Текст тайтла |
| `on_salary.blocked_afk` | Одна строка при заблокированной выплате; пустая строка = тишина |
| `command.*` | Тексты команды: `no_permission`, `usage`, `unknown_player`, `reload_success` |
| `command.info.self` / `command.info.other` | Информация о своей / чужой зарплате |
| `command.list.header` / `entry` / `empty` | Оформление списка групп |
| `command.status.*` | Значения `{status}`: `online`, `afk`, `offline`, `no_group` |
| `command.startup_failed` | Ответ `/salary`, если старт плагина завершился внутренней ошибкой |
| `console.enabled` | Полностью выключает сообщения плагина в консоли |
| `console.*` | Тексты консоли: `startup`, `shutdown`, `economy_hooked`, `economy_waiting`, `economy_late`, `economy_missing`, `startup_failed`, `vault_paused`, `vault_resumed`, `reloaded`, `invalid_value`, `group_no_salary`, `groups_section_missing`, `groups_empty`, `unknown_sound`, `command_missing`, `placeholders_no_api`, `deposit_failed`, `deposit_exception` |

Все строки поддерживают цветовые коды `&` и HEX `#RRGGBB`.

## Плейсхолдеры

**Внутренние** (работают всегда):

| Плейсхолдер | Значение |
|---|---|
| `{money}` | Сумма выплаты |
| `{player}` | Ник игрока |
| `{group}` | Название группы |
| `{interval}` | Интервал выплаты в секундах |
| `{status}` | Статус игрока (`messages.command.status.*`) |
| `{commands}` | Количество команд у группы |
| `{next}` | Обратный отсчёт до следующей выплаты: личное окно в `PERSONAL`, ближайший payday в `GLOBAL` |
| `{prefix}` | Префикс из `messages.prefix` - только там, где указан в шаблоне |

**Внешние** — любые `%...%` через PlaceholderAPI, например `%player_balance%`
или `%servertime_HH:mm%`.

В `commands` доступны `{player}`, `{money}`, `{group}`.

## AFK-защита

Проверка AFK в MoonSalary — внутренний предикат для выплат, а не второй
AFK-плагин: она **ничего не пишет в чат, не играет звуки и не показывает тайтлы**,
поэтому спокойно соседствует с любыми сторонними AFK-плагинами
(EssentialsX AFK, CMI и т.д.). Единственный видимый эффект — игрок, который
стоит на месте дольше `afk.threshold`, не получает зарплату в этот интервал.

- Позиция игрока снимается в основном потоке и хранится как неизменяемый снимок
  (мир + координаты + поворот), поэтому данные не «протекают» между игроками.
- Точка отсчёта создаётся при входе на сервер — сразу после захода игрок не считается AFK.
- Как только игрок сдвинулся с места, отметка AFK снимается, а отсчёт начинается заново.
- Состояние у каждого игрока своё: AFK одного игрока никак не влияет на выплаты другим.
- `moonsalary.bypass.afk` позволяет получать зарплату стоя на месте
  (в событии `SalaryPayEvent` такой игрок приходит со статусом `BYPASSED`).
- Если хочется объяснять игроку причину блокировки, есть один опциональный ключ —
  `messages.on_salary.blocked_afk` (пустая строка по умолчанию = полная тишина).
- Для интеграций тихо публикуется событие `PlayerAfkEvent` — его видит только код,
  но не игроки.

## API

Плагин можно расширять из других плагинов — достаточно добавить его в `softdepend`.

### `SalaryPayEvent`

Вызывается перед каждой выплатой, отменяемое.

```java
@EventHandler
public void onSalaryPay(SalaryPayEvent event) {

    Player player = event.getPlayer();
    SalaryGroup group = event.getGroup();

    double amount = event.getAmount();
    AfkState afkState = event.getAfkState(); // ACTIVE | BYPASSED | AFK

    if (player.hasPermission("myplugin.no_salary")) {
        event.setCancelled(true);
    }
}
```

### `PlayerAfkEvent`

Вызывается при смене AFK-состояния игрока.

```java
@EventHandler
public void onPlayerAfk(PlayerAfkEvent event) {

    if (event.isAfk()) {
        event.getPlayer().sendMessage("Ты ушёл в AFK");
    }
}
```

### Получение сервисов

```java
MoonSalary plugin = (MoonSalary) Bukkit.getPluginManager().getPlugin("MoonSalary");

GroupRegistry groups = plugin.getGroupRegistry();
SalaryGroup group = groups.getPlayerGroup(player);

if (group != null) {
    double salary = group.getSalary();
}
```

## Сборка из исходников

```bash
git clone https://github.com/NeyOff/MoonSalary.git
cd MoonSalary
mvn clean package
```

Готовый файл появится в `target/MoonSalary-2.0.0.jar`.

В IDE проект открывайте через `pom.xml` (Import as Maven project): все зависимости,
включая аннотации `org.jetbrains` (идут транзитивно от spigot-api), подтянутся сами.

Запуск тестов:

```bash
mvn test
```

## Структура проекта

```
com.ney.moonsalary
├── MoonSalary                     - точка входа, сборка всех компонентов
├── command
│   ├── CommandDispatcher          - регистрация команд в одном месте
│   └── SalaryCommand              - /salary (info | reload | list)
├── config
│   ├── MoonSalaryConfig           - контракт конфигурации (интерфейс)
│   ├── ConfigManager              - чтение config.yml + кэш значений
│   └── type
│       ├── AfkState               - ACTIVE | BYPASSED | AFK
│       ├── PayoutMode             - GLOBAL | PERSONAL
│       ├── SalaryGroupSettings    - record настроек группы
│       └── SoundSettings          - record настроек звука
├── event
│   ├── EventDispatcher            - регистрация слушателей
│   ├── SalaryPayEvent             - событие выдачи зарплаты (Cancellable)
│   └── PlayerAfkEvent             - событие смены AFK-состояния
├── listener
│   ├── PlayerConnectionListener   - вход/выход игрока (чистка AFK-данных)
│   └── VaultStateListener         - пауза/возобновление выплат при жизни Vault
├── registry
│   ├── GroupRegistry              - реестр групп + выбор группы по приоритету
│   └── SalaryGroup                - неизменяемая модель группы
├── service
│   ├── AfkTracker                 - per-player AFK (позиции + отметки)
│   ├── EconomyService             - обёртка над Vault Economy
│   ├── MessageService             - сообщения, тайтлы, звуки, плейсхолдеры
│   ├── PayoutSchedule             - расписание персональных выплат (окна без догона)
│   └── SalaryPayoutService        - выдача: деньги → команды → чат → тайтл
├── task
│   ├── AfkCheckTask               - цикл проверки AFK (тихий)
│   ├── GlobalSalaryTask           - payday: выплата всем по фиксу
│   ├── PersonalSalaryTask         - личные сроки игроков от захода
│   └── TaskScheduler              - запуск/остановка/перезапуск задач
└── util
    ├── HexColorUtil               - HEX-цвета (#RRGGBB → &x&R&R&G&G&B&B)
    └── PlaceholderUtil            - PlaceholderAPI через рефлексию + {токены}
```
